### Decisions for the UI tickets (T-09 onward)

1. **Actions:** task mutations **don't** call `refresh()`. The list view and panel keep data in
   TanStack Query (`['tasks', listId]`, `['task', taskId]`) with optimistic updates, rollback and
   invalidation (Section 4). Read actions (`getListViewAction`, `getTaskAction`, `getMyTasksAction`)
   are what those queries refetch with.
2. **Row order** in `getListView` is by context position; the client builds the NESTED tree
   (roots = rows whose `parentId` isn't in the result) and applies the sort (6.7).
3. `setCompleted` defaults `includeSubtasks` to **false**; the UI asks "Also complete N open
   subtasks?" (default Yes) and passes the answer (6.2.4).
4. Descendants of a linked task show in the list but aren't marked linked; only the linked
   root carries the link icon (9.2).
