### 3. FullCalendar

**Options:**
- plugins `[timeGridPlugin, dayGridPlugin, interactionPlugin]`, `initialView: "timeGridWeek"`, `firstDay: 1`,
  `timeZone: "local"`;
- `nowIndicator`, `scrollTime: "08:00:00"`;
- `slotDuration: "00:30:00"`, `snapDuration: "00:15:00"`, `slotLabelFormat: { hour: "numeric", meridiem: "short" }`;
- `allDaySlot: true`, `dayMaxEvents: true`;
- `editable: true`, `eventDurationEditable: true`, `droppable: true`, `height: "100%"`.

**Data:**
- Keep `range` state from `datesSet` (`{ start: info.start.toISOString(), end: info.end.toISOString() }`) and the
  title.
- `useTimeBlocks(spaceId, range)` and `useDueChips(spaceId, range)` feed `events`:
  - **blocks** → `{ id, title: taskTitle, start, end, extendedProps: { kind: "block", taskId, color, completed },
    editable: !id.startsWith("temp-") }`;
  - **due chips** → `{ id: "due-" + taskId, title, start: "YYYY-MM-DD", allDay: true, editable: false,
    extendedProps: { kind: "due", taskId, color } }`. Take the date from the UTC parts of `dueDate`: date-only
    values are UTC midnight.

**`eventContent` (render it yourself):**
- **Block:**
  - background `color-mix(in oklab, <color> 14%, var(--background))`, a 3px left bar in `<color>`, `rounded-[5px]`,
    `px-1.5 py-0.5`, full height;
  - the title 12px medium (line-clamped), the time range 11px muted under it when the event is tall enough;
  - a completed task's block is struck through and muted;
  - on hover, a small `⋯` at the top right opens a `DropdownMenu` with **Remove from calendar** (`IconCalendarX`).
    Stop `pointerdown`, `mousedown` and `click` on that button, so it neither starts a drag nor opens the task.
    Picking the item calls `deleteTimeBlock.mutate`.
- **Due chip:** a pill (`rounded px-1.5 text-[11px] bg-pill`) with a 6px dot in the color and the title.

**Interactions:**
- `eventClick`: open the task dialog with `router.replace(\`${pathname}?task=${taskId}\`, { scroll: false })`.
- `eventDrop` and `eventResize` → `updateTimeBlock.mutateAsync({ timeBlockId: event.id, taskId, start:
  event.start.toISOString(), end: event.end.toISOString() })`. On failure, call `info.revert()`.
- `drop` (a rail task dropped):
  - start = `info.date`. When `info.allDay` (month view or the all-day row), use 09:00 local on that day instead;
  - end = start + 60 minutes;
  - `createTimeBlock.mutateAsync({ taskId, taskTitle, projectColor, start, end, tempId: \`temp-${crypto.randomUUID()}\` })`,
    with the values from the dragged element's data attributes.
