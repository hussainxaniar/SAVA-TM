### Rules (same as T-05)

- `"use client"` everywhere. Actions return `{ ok: true, data } | { ok: false, error: { code, message } }`.
  Project actions call `refresh()` on the server, so after success the layout re-renders
  with new `projects` props. Don't refetch.
- Errors: forms inline (`<p role="alert" className="text-sm text-destructive">`), everything
  else `toast.error(message)` from `sonner`. Success is silent.
- **Base UI, not Radix:** no `asChild`. Use `render={<Button … />}` on triggers, and
  `nativeButton={false}` when a `Button` renders a `Link`. `Select` needs `items`.
  `AlertDialogAction` doesn't close by itself, so control `open`. `DropdownMenuLabel`
  must sit inside `DropdownMenuGroup`.
- Visuals (9.8): 14px base, neutral slate, 4px grid, `rounded-md`. Sidebar rows are
  `h-8 px-2 text-sm rounded-md`, hover `bg-accent`, active `bg-accent font-medium text-foreground`,
  idle `text-muted-foreground`. Icons from `lucide-react`, `size-4`.

### 2. `ProjectTree({ spaceId, projects, canArchiveProjects })`

- **Empty:** `projects.length === 0` → muted `px-2 text-sm` "No projects yet".
- **Drag to reorder** with `@dnd-kit/core` + `@dnd-kit/sortable` (installed; do **not**
  import `@dnd-kit/utilities` or `@dnd-kit/modifiers`, they aren't dependencies):
  - `DndContext` with `closestCenter` and sensors
    `useSensor(PointerSensor, { activationConstraint: { distance: 4 } })` and
    `useSensor(KeyboardSensor, { coordinateGetter: sortableKeyboardCoordinates })`;
    `SortableContext items={ids} strategy={verticalListSortingStrategy}`.
  - Each project row uses `useSortable({ id })`. Style:
    `transform: transform ? \`translate3d(${transform.x}px, ${transform.y}px, 0)\` : undefined, transition`,
    and `opacity-50` while `isDragging`.
  - The **drag handle** is a `GripVertical` icon button shown on row hover
    (`opacity-0 group-hover:opacity-100`), with `{...attributes} {...listeners}` on the
    handle only, so clicking the name still navigates. `aria-label="Reorder <name>"`.
  - **Optimistic order:** keep `items` in state, derived from props. When the `projects` prop
    changes identity, reset it by adjusting state during render:
    `const [prev, setPrev] = useState(projects); if (projects !== prev) { setPrev(projects); setItems(projects); }`.
    `onDragEnd({ active, over })`: if `over` and ids differ, `next = arrayMove(items, from, to)`
    (from `@dnd-kit/sortable`), `setItems(next)`, then call
    `reorderProjectAction({ projectId: active.id, beforeId: next[i - 1]?.id ?? null, afterId: next[i + 1]?.id ?? null })`
    where `i` is the moved project's new index. On failure: `setItems(projects)` and `toast.error`.
- **Project row** (`group relative flex items-center gap-1`):
  handle · chevron button (`ChevronRight`, `rotate-90` when expanded, `aria-expanded`,
  `aria-label="Toggle <name>"`) · the project `Link` to `/s/${spaceId}/p/${id}` (it
  redirects to the first list) containing the **color dot** (`size-2.5 rounded-full`, inline
  `style={{ backgroundColor: color }}`), or the `icon` emoji instead of the dot when set, then the
  name (`truncate`) · a `⋯` menu trigger (`MoreHorizontal`, `Button variant="ghost" size="icon-xs"`,
  visible on row hover, or while its menu is open).
- **Expanded state:** default expanded. Persist collapsed projects in `localStorage` under
  `sava.sidebar.collapsed` as a JSON array of project ids. Read it **in `useEffect`** after
  mount (not during render, to avoid hydration mismatches), and wrap reads and writes in `try/catch`.
- **Children** when expanded (indented `pl-7`): each list as a `Link` to
  `/s/${spaceId}/p/${projectId}/l/${listId}` with a `Hash` icon and the name. It's active
  when the pathname starts with that href. Then, if the project has docs, a small label
  "Docs" (`pl-2 text-xs text-muted-foreground mt-1`) and each doc as a `Link` to
  `/s/${spaceId}/p/${projectId}/d/${docId}/${firstPageId}` with a `FileText` icon. If
  `firstPageId` is null, render the doc title as plain muted text.
- **`⋯` menu** (`DropdownMenu`):
  - **Rename** → inline edit: the name becomes an `Input` (`h-7 text-sm`, autoFocus,
    text selected). Enter or blur saves if changed and non-empty, Esc cancels. Validate with
    `updateProjectSchema`, call `updateProjectAction({ projectId, name })`, `toast.error` on failure.
  - **Color** → `DropdownMenuSub` + `DropdownMenuSubTrigger` "Color", whose content lists
    `PROJECT_COLORS` from `@/lib/project-colors` as items with a swatch dot and name, plus a
    `Check` on the current color. Selecting one calls `updateProjectAction({ projectId, color })`.
  - **Project settings** → navigates (`router.push`) to `/s/${spaceId}/p/${id}/settings`.
  - Only if `canArchiveProjects`: a `DropdownMenuSeparator`, then **Archive project**
    (`variant="destructive"`). It opens a controlled `AlertDialog` rendered **outside** the menu,
    titled "Archive <name>?" with the description "It disappears from the sidebar for everyone.
    Nothing is deleted." It has Cancel and a destructive "Archive" action that calls
    `archiveProjectAction({ projectId })`. If the user is currently inside that project
    (pathname starts with `/s/${spaceId}/p/${id}`), `router.push(\`/s/${spaceId}\`)` after success.

### 3. `NewProjectDialog({ spaceId, projects })`

- Renders its own trigger: a full-width sidebar row "New project" with a `Plus` icon
  (same row styles as nav items), as `<DialogTrigger render={<button type="button" className="…" />}>`.
- Controlled `Dialog` (`open`/`onOpenChange`). `DialogContent` holds `DialogHeader` →
  `DialogTitle` "New project", then a form:
  - **Name**: `Label` + `Input` (autoFocus, `maxLength={80}`, placeholder "e.g. Website relaunch").
  - **Color**: a row of 10 round swatch buttons from `PROJECT_COLORS` (`size-6 rounded-full`,
    `aria-label={name}`, `aria-pressed`, selected one gets `ring-2 ring-offset-2 ring-ring`).
    Default is the first (Slate).
  - **Statuses**: `Label` "Statuses" + `Select` with the sentinel value `"default"` →
    "Default (To do, In progress, Done)", plus one option per project →
    "Copy from <name>". Build `items` from the same list. `"default"` means don't send
    `copyStatusesFromProjectId`. Hide the Select if `projects` is empty.
  - `DialogFooter`: `DialogClose render={<Button variant="outline" />}` "Cancel", and a submit
    `Button` "Create project" ("Creating…" and disabled while pending).
- Submit: validate with `createProjectSchema`, then call
  `createProjectAction({ spaceId, name, color, copyStatusesFromProjectId? })`. On error, show it
  inline. On success, close, reset the fields, and
  `router.push(\`/s/${spaceId}/p/${res.data.projectId}/l/${res.data.firstListId}\`)`.

### 4. `UserMenu({ user })`

A full-width footer row `DropdownMenuTrigger` (same row styles) with an `Avatar` (`size-6`,
image or initials fallback, same initials rule as `members-table.tsx`) and the name (`truncate`).
Content (`side="top"`, `align="start"`): a `DropdownMenuGroup` with a `DropdownMenuLabel`
showing the name, plus the email in muted `text-xs`; a separator; **Sign out** (`LogOut` icon) →
`await authClient.signOut()` then `router.replace("/sign-in")` and `router.refresh()`.
No other items (integrations come later).
