## Architect part (done, do not change)

- `useIsMobile()` from `@/hooks/use-media-query`: true below 768px, and already true in the first paint on a phone.
- Tokens (Tailwind classes): `text-body`, `text-icon`, `text-faint`, `bg-scrim` plus the existing `text-muted-foreground`, `border-border`,
  `border-divider`, `bg-pill`, `bg-selected`, `text-selected-foreground`, `text-primary`, `bg-sidebar`, `text-overdue`, `text-success`.
- `BottomSheet`, `BottomSheetAction`, `BottomSheetOption` in `@/components/ui/bottom-sheet` (not needed in this ticket).
- `requestQuickAdd()` from `@/lib/quick-add` opens quick add. `ListIcon` in `@/components/list-icon` draws a list's icon.
- `NewProjectDialog` in `@/components/sidebar/new-project-dialog` (props: `spaceId`, `projects: {id,name}[]`, `open`, `onOpenChange`).
- `getSidebar(ctx, { spaceId })` in `@/server/services/projects` returns `SidebarDTO` (`@/server/services/types`); `listMySpaces(ctx)` in
  `@/server/services/spaces`; `getSessionUser()` in `@/server/auth`. Look at `src/app/(app)/s/[spaceId]/my-tasks/page.tsx` for how a page
  reads `params` (a Promise) and the user.

## What to build

1. **NEW `src/components/mobile/tab-bar.tsx`** (`"use client"`): `TabBar({ spaceId })`, a `<nav aria-label="Main">` with four `next/link` tabs,
   each `flex-1`, column, centred, `gap-[3px]`, min height 56px:
   | Label | href | Icon | Active when the pathname starts with |
   | --- | --- | --- | --- |
   | My tasks | `/s/{spaceId}/my-tasks` | `IconCircleCheck` | `/s/{spaceId}/my-tasks` |
   | Calendar | `/s/{spaceId}/calendar` | `IconCalendar` | `/s/{spaceId}/calendar` |
   | All tasks | `/s/{spaceId}/all` | `IconStack2` | `/s/{spaceId}/all` or `/s/{spaceId}/p/` |
   | More | `/s/{spaceId}/more` | `IconMenu2` | `/s/{spaceId}/more`, `/settings`, `/integrations`, `/notifications` under the space |
   Container: `flex shrink-0 border-t border-border bg-background px-2 pb-[env(safe-area-inset-bottom)]`. Icon `size-6`, `stroke={1.8}`
   (active: `stroke={2}`). Label `text-[11px] leading-[14px] font-medium text-muted-foreground`; active tab: icon and label `text-primary`,
   label `font-semibold`, and `aria-current="page"`.
2. **NEW `src/components/mobile/mobile-shell.tsx`** (`"use client"`): `MobileShell({ spaceId, children })`:
   `<div className="flex h-dvh flex-col bg-background">` with a scroll area
   `<div data-mobile-scroll className="relative min-h-0 flex-1 overflow-y-auto overscroll-contain pt-[env(safe-area-inset-top)]">{children}</div>`
   then `<TabBar spaceId={spaceId} />`.
3. **NEW `src/components/mobile/screen-header.tsx`**: `ScreenHeader({ title, subtitle, actions })`:
   `<header className="flex items-end pb-3 pl-4 pr-2 pt-2">`; left column `min-w-0 flex-1 flex flex-col gap-0.5`: `<h1>` with
   `text-[28px] font-bold leading-[34px] tracking-[-0.02em] text-foreground`, subtitle `<p className="text-[13px] leading-[18px] text-muted-foreground">`
   (only when given); `actions` on the right (`flex shrink-0 items-center`). Also export `HeaderIconButton` (a `<button type="button">` or, when
   `href` is passed, a `next/link`): `flex size-11 items-center justify-center text-icon`, requires `aria-label`.
4. **NEW `src/components/mobile/fab.tsx`** (`"use client"`): `AddTaskFab()`: a `<button type="button" aria-label="Add task">` that calls
   `requestQuickAdd()`. Classes: `fixed right-4 z-30 flex size-14 items-center justify-center rounded-full bg-primary text-primary-foreground shadow-lg shadow-primary/30`
   and `style={{ bottom: "calc(72px + env(safe-area-inset-bottom))" }}`. Icon `IconPlus` `size-[26px]` `stroke={2.2}`.
5. **`src/components/sidebar/sidebar.tsx`**: in `Sidebar`, when `isMobile` is true return `<MobileShell spaceId={space.id}>{children}</MobileShell>`
   (after all hooks have run). Delete the mobile top bar (`<header … md:hidden>`), the drawer and its backdrop, `drawerOpen`, the Esc effect and the
   close-on-navigation state; the toggle event only collapses the desktop sidebar now. The desktop markup stays exactly as it is.
6. **`src/app/(app)/layout.tsx`**: `h-screen` becomes `h-dvh`.
7. **NEW `src/app/(app)/s/[spaceId]/all/page.tsx`** (server component): load `getSidebar` and `listMySpaces` (for the space name) and render
   `<AllTasksView spaceId={spaceId} spaceName={…} projects={projects} />`.
8. **NEW `src/components/mobile/all-tasks-view.tsx`** (`"use client"`), following `06-all-tasks.jsx.txt`:
   - `ScreenHeader` title "All tasks", subtitle `"{n} project(s) · {spaceName}"`, action: `HeaderIconButton` with `IconPlus` (aria-label "New project")
     that opens `NewProjectDialog`.
   - One block per project. Project row: a `<button type="button" aria-expanded>` row `flex h-[52px] w-full items-center gap-2 border-t border-border pl-3 pr-1`:
     chevron (`IconChevronDown` when open, `IconChevronRight` when closed; `size-5 text-muted-foreground`), a `size-2.5 rounded-[3px]` square with
     `style={{ backgroundColor: project.color }}`, the name `min-w-0 flex-1 truncate text-left text-base font-semibold text-foreground`; when closed a
     trailing `text-[13px] text-muted-foreground` summary: `"3 lists"`, plus `" · 1 doc"` when it has docs. Next to it (a sibling, not inside the
     button) a `next/link` to `/s/{spaceId}/p/{projectId}/settings`: `flex size-11 items-center justify-center text-muted-foreground`, `IconDots`
     `size-[22px]`, `aria-label="Project settings"`.
   - Open project: its lists, then its docs. List row = `next/link` to `/s/{spaceId}/p/{projectId}/l/{listId}`:
     `flex h-12 items-center gap-3 pl-10 pr-4`, `<ListIcon>` at 20px in `text-muted-foreground` (read `src/components/list-icon.tsx` for its props),
     name `min-w-0 flex-1 truncate text-base text-foreground`, `openTaskCount` in `text-[13px] text-muted-foreground` (hide when 0).
     Doc row = link to `/s/{spaceId}/p/{projectId}/d/{docId}/{firstPageId}` with `IconFileText` (`size-5 text-muted-foreground`, `stroke={1.8}`) and the
     title; a doc whose `firstPageId` is null is not shown.
   - Which projects are closed is remembered with `useLocalStorage("sava.mobile.allTasks.closed", [] as string[])` (`@/hooks/use-local-storage`,
     returns `[value, setValue]`); every project is open by default.
   - Last row: a `<button>` "New project" `flex h-[52px] w-full items-center gap-2 border-t border-border pl-3 pr-4 text-base font-medium text-primary`
     with `IconPlus` `size-5`; opens the same dialog. No projects at all: a centred `text-[15px] text-muted-foreground` line "No projects yet." above it.
   - Bottom padding `pb-6`.
9. **NEW `src/app/(app)/s/[spaceId]/more/page.tsx`**: for now only `<ScreenHeader title="More" />` (the content is ticket M-06).
