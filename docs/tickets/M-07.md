## Architect part (done, do not change)

- Decision: on a phone the page tree is a **bottom sheet** opened from the editor's navigation bar (the design drew it as its own screen; a sheet keeps the URL
  scheme `…/d/{docId}/{pageId}` unchanged). Its rows look like the design's tree screen.
- `useIsMobile()` (`@/hooks/use-media-query`), `useKeyboardInset()` (`@/hooks/use-keyboard-inset`), `BottomSheet` (`@/components/ui/bottom-sheet`),
  `HeaderIconButton` (`src/components/mobile/screen-header.tsx`).
- `usePageTree(docId, initialTree)`, `useCreatePage(docId)` (`@/hooks/use-doc`; read `src/components/docs/page-tree.tsx` for how a page is created and opened),
  `flattenTree(tree)` (`@/lib/page-tree`) → `{ node, depth, hasChildren }[]` in display order.
- `DocTitle`, `PageEditor` in `src/components/docs/`. The slash menu: `src/components/rich-text/slash/slash-command.tsx` (positions the popup), `slash-menu.tsx`
  (keys and selection), `slash-menu-list.tsx` (the desktop list). Items are `SlashItem` (`@/lib/slash-items`): read that file for their fields.

## What to build

1. **`src/components/docs/doc-view.tsx`**: call `useIsMobile()`; when true return `<MobileDocView initialData={initialData} me={me} tree={tree} />` (after the hooks).
   Remove the phone-only "Pages" toggle bar and the `treeOpen` state (the desktop layout no longer needs the `max-md:` classes on the tree); desktop stays as it is.
2. **NEW `src/components/mobile/doc-view.tsx`** (`"use client"`): `MobileDocView({ initialData, me, tree })`:
   - Navigation bar `flex h-11 items-center px-1`: back link "All tasks" to `/s/{spaceId}/all` (`flex h-11 items-center gap-0.5 pl-1.5 pr-2 text-base text-primary`,
     `IconChevronLeft` `size-6`), spacer, `HeaderIconButton` label "Pages" with `IconListTree` `size-6` (class `text-foreground`) opening the pages sheet.
   - Title block `px-4 pb-2 pt-1`: project line (`size-2 rounded-[2px]` square in `doc.projectColor` + `doc.projectName`, `text-[13px] text-muted-foreground`) and `<DocTitle />`.
   - `<PageEditor key={page.id} docId spaceId page me />`.
   - Pages sheet: `BottomSheet` titled with the doc title. One `next/link` row per `flattenTree(tree)` entry to `/s/{spaceId}/p/{projectId}/d/{docId}/{node.id}`:
     `flex h-12 items-center gap-2 pr-4 text-base text-foreground` with `style={{ paddingLeft: 16 + depth * 28 }}`, `IconFileText` `size-5 text-muted-foreground` `stroke={1.8}`,
     the title (`min-w-0 flex-1 truncate`; "Untitled" when empty); the current page: `bg-selected font-medium text-selected-foreground` (icon too). Tapping a row closes the sheet.
     Last row: a `<button>` "New page" (`IconPlus` `size-5 text-primary`, text `text-muted-foreground`) that creates a top-level page and opens it, like the desktop tree's button.
3. **`src/components/docs/page-editor.tsx`**: phone spacing only: the container gets `max-md:px-4 max-md:pb-40 max-md:pt-2`, the page title
   `max-md:text-[26px] max-md:font-bold max-md:leading-8`. Nothing else.
4. **NEW `src/components/rich-text/slash/slash-bar.tsx`** (`"use client"`): `SlashBar({ items, selectedIndex, onSelect })`: the phone's block bar from `09-doc-editor.jsx.txt`:
   `<div role="listbox" aria-label="Insert block">` with `fixed inset-x-0 z-50 flex h-[52px] items-center gap-2 overflow-x-auto border-t border-border bg-background px-3`
   and `style={{ bottom: keyboardInset }}` (from `useKeyboardInset()`). Each item a `<button type="button" role="option" aria-selected>`:
   `flex h-9 shrink-0 items-center gap-1.5 rounded-lg px-3 text-sm font-medium` (`bg-pill text-foreground`, or `bg-selected text-selected-foreground` when selected), with the
   item's icon at `size-[18px]` (render it the way `slash-menu-list.tsx` does) and its title. `onMouseDown={(e) => e.preventDefault()}` so the editor keeps focus (and the
   keyboard stays up); `onClick` calls `onSelect(index)`. No items: render nothing.
5. **`src/components/rich-text/slash/slash-menu.tsx`**: with `useIsMobile()`, render `<SlashBar items selectedIndex={safeIndex} onSelect={(i) => command(items[i])} />`
   instead of `<SlashMenuList />` on a phone. In **`slash-command.tsx`**, the wrapper element that is positioned at the caret must not clip or move a `fixed` child: on a
   phone (check `window.matchMedia("(max-width: 767.98px)").matches` where the popup is placed) skip the caret positioning and leave the wrapper unstyled
   (no transform, no fixed size). Keep the desktop behaviour exactly.
