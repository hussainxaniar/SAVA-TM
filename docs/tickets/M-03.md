## Architect part (done, do not change)

- The task dialog (`src/components/task-dialog/task-dialog.tsx`) is already full screen below 768px. It owns every mutation; this ticket only adds a phone body.
- `StatusControl` is phone-aware (44px target or the pill, opens the status sheet). `MobileTaskRow` (`@/components/mobile/task-row`) without `context` is the
  subtask row. `BottomSheet`, `BottomSheetAction`, `BottomSheetOption` in `@/components/ui/bottom-sheet`.
- Helpers in `@/lib/list-view`: `formatDue(iso, hasTime, { completed })`, `quickDays()` (use the first three: Today, Tomorrow, Next week), `monthGrid(year, month)`
  (42 local days, Monday first), `sameDay(a, b)`, `dateOnlyFromLocal(day)`, `withLocalTime(day, "HH:mm")`, `localDayOf(iso, hasTime)`, `localTimeOf(iso)`,
  `MAX_TASK_DEPTH`.
- Hooks in `@/hooks/use-task`: `useEditTask().mutate({ taskId, statusId, completeSubtasks })`, `useAddSubtask().mutate({ parentId, listId, title, tempId })`
  (see how `src/components/task-dialog/subtasks.tsx` calls them). `TaskEdit` type is exported there.
- `Avatar` (`@/components/tasks/avatar-stack`), `PriorityFlag` (`@/components/tasks/priority-flag`), `DescriptionEditor`, `LinkedDocs`, `ActivitySection` in
  `src/components/task-dialog/`.

## What to build

1. **`src/components/task-dialog/task-dialog.tsx`**:
   - export `TitleEditor` and give it an optional `className` prop that replaces the text classes (`text-2xl font-semibold leading-8 tracking-[-0.015em]`) when passed;
   - call `useIsMobile()`; when it is true, inside `<DialogContent>` keep the sr-only `DialogTitle` and render, instead of `<Header />` and the two-column body:
     `error ? <ErrorState /> : !task ? <LoadingState /> : <MobileTaskBody task={task} members={members} me={me} onClose={onClose} onOpenTask={onOpenTask}
     onSetStatus={onSetStatus} onEditTask={onEditTask} onSetAssignees={onSetAssignees} onCommitTitle={(title) => editTask.mutate({ taskId: task.id, title })}
     onSaveDescription={(description) => editTask.mutate({ taskId: task.id, description })} onCopyLink={copyLink} onDelete={remove}
     canConvert={!!task.parentId} onConvert={convert} />`. The desktop branch stays exactly as it is.
2. **NEW `src/components/mobile/task-body.tsx`** (`"use client"`): `MobileTaskBody` (props above), a `flex min-h-0 flex-1 flex-col pt-[env(safe-area-inset-top)]`:
   - Header `flex h-11 shrink-0 items-center px-1`: close button (`size-11`, `aria-label="Close"`, `IconChevronDown` `size-6`), breadcrumb
     (`flex min-w-0 flex-1 items-center gap-1.5 text-sm text-muted-foreground`: project colour square `size-2 rounded-[2px]`, then a truncating
     `"{project.name}/{homeList.name}"`; when `task.breadcrumb` is not empty, append `"/"` and a button with the last ancestor's title that calls `onOpenTask(ancestor.id)`),
     menu button (`size-11`, `aria-label="Task actions"`, `IconDots` `size-6`).
   - Scroll area `min-h-0 flex-1 overflow-y-auto overscroll-contain`:
     - Title block `flex items-start pl-1 pr-4 pt-1`: `<StatusControl task statuses={task.statuses} size={24} onSetStatus />`, then
       `flex min-w-0 flex-1 flex-col gap-2 pt-2`: `<TitleEditor key={task.id} className="text-xl font-semibold leading-7 tracking-[-0.01em]" />` and
       `<DescriptionEditor key={task.id} description spaceId={task.spaceId} onSave />`.
     - Chips `flex flex-wrap items-center gap-2 border-b border-border py-4 pl-12 pr-4`: `<StatusControl variant="pill" />`, then three chip buttons that open their sheets.
       Chip with a value: `flex h-8 items-center gap-1.5 rounded-lg border border-border px-2.5 text-[13px] font-medium text-foreground`; empty chip:
       `border-dashed border-input text-muted-foreground` with `IconPlus` `size-4` and the label.
       - Due: `IconCalendar` `size-4` + `formatDue` label, in `text-overdue` / `text-success` by tone; empty label "Due date".
       - Priority: `<PriorityFlag size={16} />` + `"P1" | "P2" | "P3"`; empty (priority 4) label "Priority".
       - Assignees: up to 3 avatars (`size-5 text-[9px]`, overlapping `-ml-1`) + first names joined with ", " (two names, then `+n`); empty label "Assignee".
     - `<MobileSubtasks task onOpenTask />`, `<div className="px-4"><LinkedDocs task /></div>`, `<ActivitySection taskId me phone />`.
   - Task actions sheet (`BottomSheet` with `label="Task actions"`, no title): `BottomSheetOption`s "Copy link" (`IconLink`), "Convert to task" (`IconCornerLeftUp`,
     only when `canConvert`), "Delete" (`IconTrash`, `destructive`); each closes the sheet first.
3. **NEW `src/components/mobile/task-pickers.tsx`** (`"use client"`), from `03-task-pickers.jsx.txt`; each takes `open`, `onOpenChange`:
   - `DueDateSheet({ dueDate, dueHasTime, onChange })` with `onChange(edit: { dueDate: string | null; dueHasTime?: boolean })`: title "Due date", action "Done" (closes).
     Quick chips row `flex gap-2 px-4 pb-3 pt-1` (Today, Tomorrow, Next week, No date; chip `h-8 rounded-lg border border-border px-2.5 text-[13px] font-medium`,
     the one matching the current day `border-transparent bg-selected text-selected-foreground`): picking one applies it and closes. Month header
     `flex h-11 items-center border-t border-divider pl-4 pr-1` ("October 2026" `text-[15px] font-semibold`, two 44px buttons `IconChevronLeft`/`IconChevronRight`
     `size-[22px] text-icon`, aria-labels "Previous month"/"Next month"). Weekday row (M T W T F S S, `text-xs text-muted-foreground`, `grid grid-cols-7 px-3`), then
     the 42 days `grid grid-cols-7 px-3`, each a `<button>` `flex h-11 items-center justify-center text-[15px]`; days outside the month `text-faint`; the selected day shows
     a `size-9 rounded-full bg-primary font-semibold text-primary-foreground` circle; today (not selected) `text-primary font-semibold`. Picking a day applies it and keeps the
     sheet open. Time row `flex h-[52px] items-center gap-3 border-t border-divider px-4`: `IconClock` `size-5 text-icon`, "Time" `flex-1 text-base`, and

     `{ dueDate: withLocalTime(day ?? today, time), dueHasTime: true }`; clearing it gives `{ dueDate: dateOnlyFromLocal(day), dueHasTime: false }`. A day pick keeps the time.
   - `AssigneesSheet({ members, assignees, meId, onChange })` with `onChange(assignees: UserLite[])`: title "Assignees", action "Done". Search field
     (`mx-4 mb-2 mt-1 flex h-10 items-center gap-2 rounded-[10px] bg-pill px-3`, `IconSearch` `size-[18px] text-muted-foreground`, input `text-[15px]`, placeholder
     "Search people"). Member rows `flex h-14 w-full items-center gap-3 px-4` (`aria-pressed`): `<Avatar className="size-8 text-xs" />`, name `text-base` (and "You"
     in `text-xs text-muted-foreground` under the signed-in user's name), `IconCheck` `size-[22px] text-primary` when assigned. A tap toggles: removes, or appends at the end.
   - `PrioritySheet({ priority, onChange })`: title "Priority"; four `BottomSheetOption`s (`selected` for the current one): "P1 · Urgent", "P2 · High", "P3 · Medium" with
     `<PriorityFlag size={22} />`, and "No priority" (value 4) with `IconFlag` `size-[22px] text-faint`; a pick calls `onChange` and closes.
