- `src/lib/list-view.ts` date helpers (tested). Storage rule: a date-only value is UTC midnight of the calendar day;
  a value with a time is the instant.
  - `dateOnlyFromLocal(day)`: store a picked day without a time.
  - `withLocalTime(day, "HH:mm")`: store a day with a time.
  - `localDayOf(iso, hasTime)`: back to a local day (for the selected cell).
  - `localTimeOf(iso)`: the "HH:mm" of a timed value.
  - `quickDays(now?)`: Today / Tomorrow / Next week / Next weekend.

### 1. Date picker (`date-picker.tsx`)

`DatePicker({ day, time, allowTime, onChange })`. `day: Date | null` is a local day; `time: string | null` is "HH:mm";
`onChange(day, time)`. Rendered inside a `PopoverContent` (`w-[264px] p-2`):
1. **Quick picks**: `quickDays()` as 32px rows: the label on the left, the short weekday ("Thu") muted on the right.
   Clicking one calls `onChange(day, time)`.
2. **Month**: a header "October 2026" (13px semibold) with ‹ › buttons (`IconChevronLeft`/`IconChevronRight`, 24px
   ghost). Below it, a 7-column grid with the headings Mo Tu We Th Fr Sa Su (11px muted) and the 42 days from
   `monthGrid`. Each day is a 32×32 button (13px):
   - days outside the month: muted;
   - today: `ring-1 ring-primary/40`;
   - the selected day: `bg-primary text-primary-foreground`.

   The month starts at the selected day's month, else today's.
3. **Time** (only when `allowTime`): with no time, an "Add time" text button (`IconClock`). With a time, an
   `<input type="time">` (`h-8 rounded-md border px-2 text-sm`) and a small × that sets the time to null.
   Changing the time calls `onChange(day ?? today, time)`.
4. **Footer**: a "Clear" text button (muted) → `onChange(null, null)`.

Picking a day keeps the popover open only when `allowTime` (so a time can be added next); otherwise close it.

### 2. Properties column (`properties-column.tsx`)

- **Assignees**: the section title row gets a `+` (same style as the Lists `+`) that opens an **assignee picker**
  (`assignee-picker.tsx`, inside a `PopoverContent w-64`):
  - a borderless search input (placeholder "Search members");
  - member rows, 32px: `Avatar` (20px) + name + an `IconCheck` on assigned ones.

  Clicking a row toggles that member; the popover stays open. The new full list is: the current assignees in
  order, minus the toggled one, or plus the toggled one at the end. Call `useSetAssignees().mutate({ taskId,
  assignees })`. The assignee rows keep their look and get a small × on hover (`aria-label="Unassign <name>"`)
  that removes that one.
- **Dates**: the value part of each of "Start" and "Due" becomes a button that opens a `Popover` with the
  `DatePicker`. When empty, the button says "None" (muted).
  - **Start**: `allowTime={false}`. `onChange(day)` → `editTask.mutate({ taskId, startDate: day ?
    dateOnlyFromLocal(day) : null })`.
  - **Due**: `allowTime`. `onChange(day, time)` →
    - no day → `{ dueDate: null }`;
    - a day and a time → `{ dueDate: withLocalTime(day, time), dueHasTime: true }`;
    - a day only → `{ dueDate: dateOnlyFromLocal(day), dueHasTime: false }`.

    Its current value comes from `localDayOf(task.dueDate, task.dueHasTime)` and
    `task.dueHasTime ? localTimeOf(task.dueDate) : null`.

  Labels and colors stay `formatDue` (Due: red when overdue, green when today; Start never colored).
- **Priority**: the value becomes a `DropdownMenu` trigger (flag + "P1"… or muted "None"). The menu is a
  `DropdownMenuRadioGroup` of `PRIORITY_META` (flag + label, `closeOnClick`) → `editTask.mutate({ taskId, priority })`.

### 3. Row menu: Due date (`task-row-menu.tsx`, handler in `list-view.tsx`)

Add a **Due date** submenu (`IconCalendar`) after Priority:
- the `quickDays()` items (label + muted short weekday);
- a separator, then **No date** (only when the task has one).

`list-view.tsx` owns the handler: `updateTask.mutate({ taskId, dueDate: dateOnlyFromLocal(day), dueHasTime: false })`
or `{ taskId, dueDate: null }`. `updateTask` is the existing `useUpdateTask(listId)`.
