## Architect part (done)

- `getMyTasks` → `MyTasksDTO = { tasks: MyTaskDTO[]; statusesByProject }`.
  - Each `MyTaskDTO` is a `TaskRowDTO` plus `projectId`, `projectName`, `projectColor` and `listName`.
  - `statusesByProject[projectId]` gives each row's status-menu statuses.
- `src/app/(app)/s/[spaceId]/my-tasks/page.tsx` renders `<MyTasksView spaceId initialData />`.
  `src/components/my-tasks/my-tasks-view.tsx` is a stub with the props type: implement it there.
- `src/lib/my-tasks.ts` (tested): `groupMyTasks(tasks)` → the five groups in order, each already sorted:
  **Overdue**, **Today**, **Next 7 days**, **Later**, **No date**. Empty groups are included; hide them.
- `src/hooks/use-my-tasks.ts`:
  - `useMyTasks(spaceId, initialData)`.
  - `useMyTaskStatus(spaceId)` → `mutate({ taskId, title, from: task.status, to: newStatus, completeSubtasks })`.
    Moving into a DONE status removes the row at once and shows the 10-second "Completed" toast with **Undo**.
- Every task-dialog edit now also refreshes My Tasks. A re-dated task moves group; unassigning yourself removes it.

### 1. Page layout (mirror the list view)

- **Header band:** the same band and paddings as `ListHeader`, minus the breadcrumb, Share, View menu and `⋯`.
  - Title "My Tasks" at 28px semibold.
  - Subtitle in the same muted style: "N open tasks" ("1 open task" when there's one).
- **Body:** the same centered max-width container and margins as the list view's groups.

### 2. Groups

For each non-empty group from `groupMyTasks(data.tasks)`, a collapsible header styled like `StatusGroup`'s:
- the chevron;
- a pill with the label, uppercase 12px semibold, `bg-pill`. The **Overdue** label is `text-overdue`. No status
  glyph in the pill;
- the count.

The collapsed state is per group, kept in `useLocalStorage("sava.myTasks.collapsed", [] as string[])`. Group header
spacing matches the list view (`mt-7` for the first group, `mt-6` after).

### 3. Rows (like the list's Separate rows)

`border-b border-divider`, hover tint like the list rows, `py-2.5`, `items-start`. Left to right:
1. **Status control:** `StatusControl` from `@/components/tasks/status-icon` with
   `statuses={data.statusesByProject[task.projectId]}` and
   `onSetStatus={(t, statusId, completeSubtasks) => setStatus.mutate({ taskId: t.id, title: t.title, from: t.status,
   to: statuses.find(s => s.id === statusId)!, completeSubtasks })}`. Wrap it in a span that stops click
   propagation (as `task-row.tsx` does), so it doesn't open the dialog.
2. **Two lines:**
   - the title, 14px; medium weight when the task has subtasks;
   - a muted 12px meta line: an 8px rounded-[2px] square in `projectColor`, then `projectName / listName`, then
     ` · ↳ parentTitle` when `parentTitle` is set.
3. **Right side:**
   - the due label, `formatDue(dueDate, dueHasTime)`: 12px, `text-overdue` when overdue, `text-success` today,
     muted otherwise;
   - then `PriorityFlag` for P1–P3, in a fixed-width slot so flags line up.

Clicking a row opens the task dialog: `router.replace(\`${pathname}?task=${task.id}\`, { scroll: false })`. There's
no inline add, no drag and no row menu on this page.

### 4. ↑/↓ in the dialog

Publish the ids of the rows on screen (open groups, in order) with `publishTaskOrder(ids)` in an effect, and
publish `[]` on unmount, exactly like `list-view.tsx`.

### 5. Empty state

With no open tasks at all, show this centered under the header:
- "Nothing assigned to you right now." (14px, medium);
- "Tasks assigned to you in any project show up here." (13px, muted).
