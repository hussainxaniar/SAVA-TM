## Architect part (done)

- `src/lib/quick-add-parser.ts` (+ 23 tests in `tests/lib/quick-add-parser.test.ts`):
  - `parseQuickAdd(text, { members, lists, now?, ignore? })` → `{ title, dueDate, dueHasTime, priority, assigneeIds, listId, tokens }`.
    Tokens are natural dates (chrono-node), `p1`–`p4`, `@member`, `#list`. Recognised tokens are removed from
    `title`; `tokens` lists the applied ones in text order (`kind`: `date` | `priority` | `assignee` | `list`).
  - `tokenKey(token)`: put it in `ignore` to keep a token as plain title text (the chip's ×).
  - `memberHandle(member, members)` / `listHandle(list)`: what autocomplete inserts after `@` / `#`.
  - `activeMention(text, caret)` → the `@…`/`#…` word at the caret (`{ kind, query, start, end }`) or null;
    `applyMention(text, mention, handle)` → `{ text, caret }` with the handle and a trailing space inserted.
- `src/lib/last-list.ts`: `readLastList(spaceId)`, `rememberLastList(spaceId, listId)` (localStorage, safe).
- `src/app/(app)/s/[spaceId]/layout.tsx` mounts `<QuickAddDialog spaceId projects members />` once per space
  shell. `src/components/quick-add/quick-add-dialog.tsx` is a stub with the props type: implement it there.
- `src/lib/quick-add.ts`: `QUICK_ADD_EVENT` / `requestQuickAdd()` (the sidebar's **Add task** button fires it).

### 1. Opening and closing

- The dialog is controlled by `open` state in `QuickAddDialog` (always mounted; only the popup renders when open).
- Open it on `QUICK_ADD_EVENT` (window listener) and on the **`q`** key: a `keydown` listener on `window` that
  opens when `e.key` is `q` or `Q`, no Ctrl/Meta/Alt, `!e.repeat`, `!e.isComposing`, the target is not an
  `input`, `textarea`, `select` or `[contenteditable]` element, and no other dialog is open
  (`document.querySelector('[role="dialog"], [role="alertdialog"]')` is null). Call `e.preventDefault()` so the
  `q` isn't typed into the input.
- Closing (Esc, click outside, Cancel, after saving) resets the text, the dismissed tokens and the picked list.
- Remove the now-unused `QUICK_ADD_EVENT` listener (the `useEffect` "The sidebar's Add task button…") and its
  import from `src/components/tasks/list-view.tsx`. In the same file, add
  `useEffect(() => rememberLastList(spaceId, listId), [spaceId, listId])` (import from `@/lib/last-list`).

### 2. Target list

`useParams()` gives `{ spaceId, projectId?, listId? }`. The **base list** is, in order:
1. the list the user picked in the footer picker (see 4), if any;
2. the route's `listId`, if it exists in `projects`;
3. the route's `projectId` → that project's first list;
4. `readLastList(spaceId)`, if it still exists in `projects` (read it when the dialog opens, not during render);
5. the first list of the first project that has one.

If there is no list at all, show the muted text "Create a project first" in the footer and disable saving.
`#list` tokens are parsed against the **base list's project** lists; a matched `#list` wins over the base
list. The final list is `parsed.listId ?? baseList.id`.

### 4. Saving

`Enter` in the input (when suggestions aren't showing) or clicking **Add task** saves, if allowed:

```ts
const createTask = useCreateTask(finalListId);   // in QuickAddDialog itself, not inside the popup
const row = await createTask.mutateAsync({
  tempId: `temp-${crypto.randomUUID()}`,
  listId: finalListId,
  title: parsed.title,
  priority: parsed.priority ?? undefined,
  dueDate: parsed.dueDate ?? undefined,
  dueHasTime: parsed.dueHasTime,
  assigneeIds: parsed.assigneeIds,
});
```

- Close the dialog **before** awaiting (optimistic: the row appears at once when that list is on screen).
- `rememberLastList(spaceId, finalListId)`.
- On success: `router.refresh()` (updates the sidebar's open-task counts) and
  `toast.success(\`Added to ${listName}\`, { action: { label: "Open", onClick: () => router.push(url) } })`
  where `url` is `/s/${spaceId}/p/${projectId}/l/${listId}?task=${row.id}` (T-11 opens the task from `?task=`).
- On failure the hook already rolls back and shows an error toast: wrap `mutateAsync` in `try/catch` and do
  nothing else in `catch`.
