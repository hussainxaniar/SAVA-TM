### Rules later tickets must follow

1. **Error codes:** a non-member gets `NOT_FOUND` from `requireMember`/`requireRole` (same
   as a missing entity, so existence never leaks). A member with too low a role gets
   `FORBIDDEN`. (See docs/questions.md Q1 — 7.4's comment says FORBIDDEN.)
2. **Service pattern:** `const spaceId = await spaceIdOfX(id); await requireRole(ctx.userId,
   spaceId, PERMISSIONS.editStatuses)`, or `requireMember` for ungated actions. Never take
   `spaceId` from client input for an existing entity.
3. **Pages** build `ctx` with `{ userId: (await getSessionUser()).id }`.
4. **Service tests** use `tests/helpers/db.ts`: call `resetDb()` in `beforeAll`, then
   `makeUser()` / `makeSpace({ label: role })`. Tests run against the `test` schema of
   `DIRECT_URL` (migrated automatically by `tests/setup/global-db.ts`), or against
   `TEST_DATABASE_URL` if set. Files run serially.

### Incident during this ticket

The first version of `resetDb()` truncated tables in `current_schema()`. Prisma's
`?schema=test` qualifies table names but doesn't change the search path, so it
truncated the **dev `public` schema** (only the T-02 seed data was there). The seed was
re-run. `resetDb()` now takes the schema from `DATABASE_URL` and refuses `public` unless
`TEST_DATABASE_URL` is set. Verified: dev row counts are unchanged across a full test run.
