## Architect part (done, do not change)

- `MobileTaskRow` (`@/components/mobile/task-row`): props `task`, `statuses`, `context?` (omit it here), `nested?`, `onOpenTask(taskId)`,
  `onSetStatus(task, statusId, completeSubtasks?)`. `ScreenHeader`/`HeaderIconButton`, `AddTaskFab` in `src/components/mobile/`.
- `BottomSheet` (`open`, `onOpenChange`, `title`, `action`, children), `BottomSheetAction`, `BottomSheetOption` (`icon`, `selected`, `destructive`,
  `trailing`) in `@/components/ui/bottom-sheet`.
- Hooks in `@/hooks/use-list-view`: `useListView(listId, initialData)` → `{ data }`; `useSetStatus(listId).mutate({ taskId, statusId, completeSubtasks })`;
  `useCreateTask(listId).mutate({ tempId: \`temp-${crypto.randomUUID()}\`, listId, title, statusId, parentId: null })`;
  `useRenameList(listId).mutate({ name })`; `useSetSubtaskDisplay(listId).mutate({ subtaskDisplay: "NESTED" | "SEPARATE" })`.
- `buildGroups(data.tasks, data.statuses, { mode: data.list.subtaskDisplay, sort, collapsed: new Set() })` (`@/lib/list-view`) → `StatusGroup[]`
  (`status`, `rows: { task, indent, hasChildren, showParent }[]`, `count`). `StatusGlyph` (`@/components/tasks/status-icon`, props `status`, `statuses`,
  `size`, `pill`). `useLocalStorage(key, fallback)` → `[value, setValue]`. `useIsMobile()` (`@/hooks/use-media-query`).
- The desktop list view keeps its preferences in localStorage; use the **same keys** so both layouts agree: `sava.list.${listId}.groups`
  (`Record<string, boolean>`, open/closed per status id), `sava.list.${listId}.showCompleted` (boolean, default false), `sava.list.${listId}.sort`
  (`"manual" | "due" | "priority"`, default "manual"). A group is open when `groups[statusId] ?? (status.category === "DONE" ? showCompleted : true)`.
