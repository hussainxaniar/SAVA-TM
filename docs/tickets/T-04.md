### 1. `CreateSpaceForm` — `src/components/onboarding/create-space-form.tsx`

Rendered on `/` under the heading "Create your space" (the heading and intro text are
already in the page — do not repeat them). Keep the export name and the empty props.

- `"use client"`. One field: `Label` "Space name" + `Input` (`id="space-name"`,
  `name="name"`, `autoFocus`, `placeholder="e.g. Acme Design"`, `maxLength={80}`).
- Submit `Button`, full width: "Create space"; while pending it is disabled and reads "Creating…".
- On submit (`e.preventDefault()`):
  1. Validate with `createSpaceSchema.safeParse({ name })` from
     `@/server/actions/spaces.schema`. If invalid, show `error.issues[0].message` inline
     and stop.
  2. `const res = await createSpaceAction({ name })` (from `@/server/actions/spaces`).
  3. `res.ok === false` → show `res.error.message` inline and re-enable the button.
  4. `res.ok === true` → `router.push(\`/s/${res.data.spaceId}\`)` (from
     `next/navigation`). Leave the button in its pending state; the page navigates away.
- Inline error: `<p role="alert" className="text-sm text-destructive">…</p>` under the input,
  exactly like `auth-form.tsx`. No toasts.
- Layout: `space-y-3` form, `space-y-1.5` for the label+input pair, same as `auth-form.tsx`.

### 2. `SpaceSwitcher` — `src/components/sidebar/space-switcher.tsx`

Rendered at the top of the 260px sidebar. Keep the export name and the props type
`{ current: SpaceSummaryDTO; spaces: SpaceSummaryDTO[] }` (import the type from
`@/server/services/types`). `SpaceSummaryDTO = { id; name; icon: string | null; role: 'OWNER' | 'ADMIN' | 'MEMBER' }`.

- `"use client"`. Built from `@/components/ui/dropdown-menu`.
- **Trigger** (`DropdownMenuTrigger`): full-width row, `h-9 rounded-md px-2 gap-2`,
  `hover:bg-accent`, left-aligned: space avatar (below, 24px) · space name
  (`text-sm font-medium truncate`, grows) · `ChevronsUpDown` icon from `lucide-react`
  (`size-4 text-muted-foreground`) on the right.
- **Avatar**: a square `rounded-md bg-primary text-primary-foreground` with centered text:
  `space.icon` if set (it is an emoji), else the first letter of the name, uppercased.
  Font `text-xs font-semibold`. 24px (`size-6`) in the trigger, 20px (`size-5`) in items.
- **Content** (`DropdownMenuContent`, keep its default width = trigger width):
  a `DropdownMenuGroup` containing a `DropdownMenuLabel` "Spaces", then one
  `DropdownMenuItem` per space, in the given order: avatar (20px) · name (`truncate`,
  grows) · role as `Owner` / `Admin` / `Member` (`text-xs text-muted-foreground`) ·
  a `Check` icon (lucide, `size-4`) only on the current space (reserve the space on
  the others so names line up, e.g. `invisible`).
- Selecting a space: `onClick={() => { if (space.id !== current.id) router.push(\`/s/${space.id}\`) }}`.
  (The server remembers the last space automatically; no cookie code here.)
- No "create space" or settings items — out of scope.

**This `dropdown-menu` is Base UI, not Radix.** There is no `asChild` prop.
`DropdownMenuTrigger` renders its own `<button>`, so style it with `className` directly.
`DropdownMenuLabel` must be inside a `DropdownMenuGroup`, or it throws at runtime.
