## Architect part (done, do not change)

- `StatusControl` (`@/components/tasks/status-icon`) is already phone-aware: below 768px it renders a 44x44 button with a 20px glyph and opens the
  status bottom sheet. Props: `task`, `statuses`, `onSetStatus(task, statusId, completeSubtasks?)`.
- `SubtaskGlyph` (same file), `PriorityFlag` (`@/components/tasks/priority-flag`, props `priority`, `size`), `Avatar`
  (`@/components/tasks/avatar-stack`, props `user`, `className`), `formatDue(dueDate, dueHasTime, { completed })` → `{ label, tone }`
  (`@/lib/list-view`; tone is `"overdue" | "today" | "default"`), `groupMyTasks(tasks)` (`@/lib/my-tasks`) → five groups with keys
  `overdue, today, next7, later, none`.
- `useMyTasks`, `useMyTaskStatus` are already called in `MyTasksView`; do not call them a second time.
- `ScreenHeader`, `AddTaskFab` from M-01 (`src/components/mobile/`). `NotificationBell` (`@/components/notifications/notification-bell`, prop `spaceId`).
- Types: `TaskRowDTO`, `MyTaskDTO`, `MyTasksDTO`, `StatusDTO` in `@/server/services/types`.

## What to build

1. **NEW `src/components/mobile/task-row.tsx`** (`"use client"`): `MobileTaskRow`, memoised.
   ```ts
   type Props = {
     task: TaskRowDTO;
     statuses: readonly StatusDTO[];
     /** Where the task lives. Given on My tasks; omitted where the list is already known (list page, subtasks). */
     context?: { projectName: string; listName: string; projectColor: string };
     /** Subtask under its parent: indented 28px. */
     nested?: boolean;
     onOpenTask: (taskId: string) => void;
     onSetStatus: (task: TaskRowDTO, statusId: string, completeSubtasks?: boolean) => void;
   };
   ```
   Markup (sizes from the design):
   - Row: `<div role="button" tabIndex={0} data-row-id={task.id}>` with `flex items-start pr-4 active:bg-sidebar`, `pl-1` (or `pl-8` when `nested`);
     click and Enter call `onOpenTask(task.id)`.
   - Status: a `<span>` that stops `click`, `keydown` and `pointerdown` propagation, containing `<StatusControl … />`.
   - Content: `flex min-w-0 flex-1 flex-col gap-1.5 border-b border-divider pb-3 pt-[11px]`.
     - Title line `flex items-start gap-3`: title `min-w-0 flex-1 text-base leading-[22px] text-foreground line-clamp-2 break-words`; a completed task
       (`task.completedAt !== null`) is `text-muted-foreground line-through`. **With `context`** the flag sits here on the right:
       `<PriorityFlag priority size={18} className="mt-0.5" />` when `task.priority < 4`.
     - Meta line `flex h-[18px] items-center gap-3 text-xs leading-4 text-muted-foreground`, shown only when it has something to show:
       - due (when `task.dueDate`): `flex shrink-0 items-center gap-1`, `IconCalendar` `size-3.5` `stroke={2}` + label; tone `overdue` → `text-overdue`,
         `today` → `text-success`;
       - subtasks (when `task.subtaskCount > 0`): `SubtaskGlyph` size 14 + `"{done}/{total}"` where done = `subtaskCount - openSubtaskCount`;
       - comments (when `task.commentCount > 0`): `IconMessage` `size-3.5` `stroke={2}` + the count;
       - a spacer `min-w-1 flex-1`;
       - avatars (when `task.assignees.length > 0`): up to 3 `<Avatar className="size-[18px] border border-background text-[8px]" />`, the 2nd and 3rd with `-ml-1`;
       - **with `context`**: `flex min-w-0 max-w-[200px] shrink items-center gap-1.5`: a `truncate text-right` span `"{projectName}/{listName}"` and a
         `size-2 shrink-0 rounded-[2px]` square in the project colour;
       - **without `context`**: the flag here, last: `<PriorityFlag priority size={16} />` when `task.priority < 4`.
2. **NEW `src/components/mobile/my-tasks.tsx`** (`"use client"`): `MobileMyTasks({ spaceId, data, onOpenTask, onSetStatus })` where `data: MyTasksDTO`,
   `onSetStatus: (task: TaskRowDTO, to: StatusDTO, completeSubtasks?: boolean) => void` (the same callbacks `MyTasksView` already has).
   - `ScreenHeader` title "My tasks", subtitle `"{n} task(s)"`, action `<NotificationBell spaceId={spaceId} />`.
   - Groups: take `groupMyTasks(data.tasks)` and merge `next7` and `later` into one group with key `upcoming`, label "Upcoming" (keep their order);
     labels: Overdue, Today, Upcoming, No date. Empty groups are not shown.
   - Group header: `flex h-11 items-center gap-2 border-b border-border px-4`, label `text-[15px] font-semibold leading-5 text-foreground`, count
     `text-[13px] text-muted-foreground`; every group except the first has `mt-5` above it. Groups do not collapse on a phone.
   - Rows: `MobileTaskRow` with `context` from the task, `statuses={data.statusesByProject[task.projectId]}`; its `onSetStatus(task, statusId, c)` finds the
     status object in that array and calls the prop.
   - No tasks: the empty state from `11-shared.jsx.txt`: centred column `gap-3 px-10 pt-24 text-center`: an 88px circle `bg-selected` with `IconCircleCheck`
     `size-11 text-primary` `stroke={1.6}`, title "Nothing on your plate" (`text-xl font-semibold`), text "Tasks assigned to you show up here, grouped by
     due date." (`text-[15px] leading-[22px] text-muted-foreground`), and a button "Add task" (`h-12 rounded-xl bg-primary px-6 text-base font-semibold
     text-primary-foreground`) that calls `requestQuickAdd()` from `@/lib/quick-add`.
   - `<AddTaskFab />` when there are tasks; `pb-24` under the list so the last row clears it.
3. **`src/components/my-tasks/my-tasks-view.tsx`**: call `useIsMobile()` with the other hooks and, just before the existing `return`, add
   `if (isMobile) return <MobileMyTasks spaceId={spaceId} data={data} onOpenTask={openTask} onSetStatus={onSetStatus} />;`. Change nothing else.
4. **`src/app/(app)/s/[spaceId]/my-tasks/loading.tsx`**: wrap the existing skeleton in `<div className="hidden md:block">` and add a phone skeleton
   `<div className="md:hidden">` from `11-shared.jsx.txt` ("Loading"): the title "My tasks" as in `ScreenHeader`, a `h-3 w-[120px] rounded-full bg-pill` bar, one
   group header bar (`h-3.5 w-[72px]`), then four rows: a 20px `rounded-full bg-pill` circle in a 44px box, and two bars (`h-3.5 bg-pill`, `h-2.5 bg-divider`,
   widths 240/120, 180/90, 270/140, 150/100). Add `animate-pulse` to the wrapper.
